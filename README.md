# Face Recognition Using Eigenfaces and PCA

Implementation of the classical Eigenfaces approach for face recognition using Principal Component Analysis (PCA).

## Features
- PCA-based dimensionality reduction
- Eigenface computation
- Whitening in eigenspace
- Automatic threshold selection
- Face recognition using Euclidean distance

## Dataset
Cropped Yale Face Dataset

- 2451 grayscale images
- 38 subjects
- 80/20 train-test split

## Results

Accuracy: 93.08%

## Technologies
- Python
- NumPy
- OpenCV
- Matplotlib
